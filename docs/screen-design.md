# 画面設計 v0.1

## 1. Dashboard

アプリを開いた最初の画面。体験の中心。

### 表示要素

- 今日の出社ボタン
- 現在のお得額または未回収額
- 定期回収率ゲージ
- 通常運賃換算の累計額
- 定期料金
- 元が取れるまでの残り出社回数
- 今月の出社回数
- 最近の出社履歴

### 状態

#### まだ元が取れていない

- 表示例: `あと 7 回で定期代を回収`
- 差額はマイナス表示
- 回収率を強調

#### 元が取れた

- 表示例: `今日までに 2,480 円お得`
- 差額はプラス表示
- お得額を強調

#### 今日すでに出社済み

- 出社ボタンを無効化
- 表示例: `今日は記録済み`

#### 定期が未登録

- 設定画面への導線を表示
- ダッシュボードの計算表示は出さない

## 2. Settings

定期情報を登録・編集する画面。

### 入力項目

- 自宅側駅
- 会社側駅
- 片道運賃
- 定期料金
- 定期開始日
- 定期終了日
- メモ

### バリデーション

- 片道運賃は1円以上
- 定期料金は1円以上
- 開始日は終了日以前
- 駅名は空にしない

## 3. History

出社履歴を確認する画面。

### 表示要素

- 出社日一覧
- 出社日の通常運賃換算額
- 削除ボタン
- 月別出社回数

### 操作

- 出社記録の削除
- 将来的には手動追加も検討

## 4. Navigation

MVPでは以下の3つで十分。

- Dashboard
- History
- Settings

## 5. UI方針

- アプリを開いたらすぐ出社ボタンを押せる
- 数字は大きく、意味が分かるラベルを付ける
- 入力画面は最小限にする
- 業務アプリではなく、個人が気分よく使える軽い雰囲気にする
