# AIDLC要件定義 v0.1

## 1. Concept

### アプリの目的

出社そのものを、少しだけ前向きな体験に変える。

定期券の料金は購入時に大きな支出として感じられる一方で、出社するたびに得られている価値は見えにくい。このアプリでは、出社1回ごとに通常運賃換算の金額を積み上げ、定期代との差分を可視化する。

### コア体験

ユーザーが出社ボタンを押すと、通常運賃換算の累計額が増える。

定期料金に近づくまでは「あと何回で元が取れる」と表示し、元が取れた後は「今日でさらに何円お得」と表示する。

## 2. User

### 主なユーザー

- 定期券で通勤している会社員
- 出社日とリモート日が混在している人
- 出社に小さなモチベーションがほしい人
- 通勤コストを自分用に記録したい人

### 初期ターゲット

まずは個人利用を前提にする。ただし、データモデルには `userId` を持たせ、将来的に複数ユーザー対応できる形にする。

## 3. Problem

- 出社が心理的に面倒に感じる
- 定期券の元が取れているか分かりにくい
- 出社回数を振り返る小さな楽しみがない
- 勤怠やカレンダーと連携する前に、自分で試せる軽いツールがほしい

## 4. MVP Scope

### Must

- 定期情報を1件登録できる
- 出社日を記録できる
- 同じ日に重複して出社記録を作らない
- 通常運賃換算の累計額を表示できる
- 定期料金との差分を表示できる
- 回収率を表示できる
- 元が取れるまでの残り出社回数を表示できる
- 出社履歴を削除できる

### Should

- 今月の出社回数を表示できる
- 最近の出社履歴を表示できる
- 定期期間外の日付は記録しない
- 出社記録後にポジティブな短い文言を表示する

### Later

- ユーザー認証
- 複数定期の管理
- カレンダー連携
- 勤怠打刻連携
- AIによる月次振り返り
- AIによる出社モチベーション文生成
- 交通費APIや経路検索連携

## 5. Success Criteria

- 出社日にボタンを押すだけで記録できる
- ダッシュボードを見て、定期が回収されている感覚が分かる
- 元が取れる前後の状態が直感的に分かる
- 自分で1か月使い続けられる程度に入力負担が少ない

## 6. AIDLC Cycle

### Discover

出社に対する気持ち、定期券の損益、記録体験を観察する。

### Define

MVPの価値を「出社ボタンを押すと得した気分になる」に絞る。

### Design

ダッシュボード中心の画面構成にする。

### Develop

ReactとSpring Boot APIで、最初は認証なしの単一ユーザーアプリとして実装する。

### Learn

実際の出社日に使い、押したくなるか、見返したくなるか、文言が嬉しいかを確認する。

### Cycle

記録負担、表示文言、ゲージ表現、履歴の見せ方を改善する。
